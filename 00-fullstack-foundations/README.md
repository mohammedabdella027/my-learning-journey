## 👋 About This Folder

This folder holds the hands-on practice I did before moving on to the AI Full-Stack course and my own projects. Each phase has its own folder, and inside each one the work is grouped by the week I did it. Only the weeks where I saved practice code have a folder.

Everything here is **practice work**. My real projects live in their own repositories.

## 🚀 Running the React Projects

The React projects in Phase 3 don't include `node_modules`, because it can be rebuilt from `package.json`. To run one:

```bash
cd <project-folder>
npm install
npm run dev
```
